About QuickNotes

QuickNotes is a simple application for capturing and organizing ideas. It allows you to quickly jot down thoughts and ideas as they come to you.

How to use QuickNotes

  1. Open QuickNotes.
  2. Create a new note.
  3. Type your idea or thought in the note field.
  4. Click the "Add Note" button to save your note.

Features

  • Quickly add and save notes.
  • View a list of all your notes.
  • Simple and user-friendly interface.

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
